# Stibnite-Based Deposit and Metal Type Classification

Python code for classifying deposit types and metal types using stibnite trace element compositions.

## Models

- Support vector machine (SVM): deposit type classification.
- Random forest (RF): metal type classification.

## Repository contents

- `svm_model.py`: Python script for SVM deposit type classification.
- `rf_model.py`: Python script for RF metal type classification.
- `README.pdf`: detailed user guide.

## Getting started

Download the repository using **Code → Download ZIP** and extract the files.

Read [the user guide](README.pdf) before running the scripts, and prepare the input data and Python environment according to its instructions.
